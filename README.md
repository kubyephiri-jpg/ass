# Jeffchilu's Store

React + Vite + Tailwind v4 storefront with Firebase Auth/Firestore and Cloudinary uploads. No backend.

    npm install
    npm run dev
    npm run build      # output: dist/

Firebase: publish `firestore.rules`, enable Email/Password auth, create the owner account, and add your
host (including the Bolt preview domain and your deployed domain) under Authentication > Settings > Authorized domains.
